## 🚀 HOW TO USE

### Launch
```
1. Open browser
2. Go to: http://localhost:8000
3. Dashboard loads automatically
```

### Explore
```
1. View 3D globe with all flight routes
2. Click any year (2017-2026) to filter
3. All sections update instantly
4. Every KPI recalculates
```

### Replay Flights
```
1. Click "✈ WATCH REPLAY" on any route
2. Watch aircraft animate along the path
3. Use controls: Play, Pause, Restart
4. Adjust speed: 0.5x, 1x, 2x, 4x
5. Use scrubber to jump to any point
```

### Ask Questions
```
1. Find Flight Agent in bottom-right corner
2. Ask questions about your flights:
   - "What was my most flown route?"
   - "How many times did I fly Air India?"
   - "Which airport did I visit most?"
   - "What was my longest flight?"
3. Get instant answers based on current filters
```

### Search History
```
1. Scroll to Flight History table
2. Search by: flight number, airline, airport, city
3. Filter by: year, airline, cabin, status
4. Click ✈ to replay any flight
5. View complete flight details
```

- **Frontend**: Pure JavaScript (no frameworks)
- **Data**: CSV parsing with quote escaping
- **Calculations**: Client-side (no backend required)
- **Visualization**: Globe.gl with SVG fallback
